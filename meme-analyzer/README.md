# 🧠 Мем-анализатор с AI

Веб-приложение, которое использует Claude AI от Anthropic для анализа текста и подбора подходящих мемов.

## ✨ Возможности

- 🤖 **AI-анализ текста** - Claude анализирует настроение, темы и контекст
- 🎭 **Подбор мемов** - Автоматический поиск подходящих мемов и постироничных образов
- 🎨 **Красивый интерфейс** - Современный и отзывчивый дизайн
- ⚡ **Быстро и просто** - Введите текст и получите результат за секунды

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка API ключа

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и добавьте ваш Anthropic API ключ:

```env
ANTHROPIC_API_KEY=sk-ant-api03-ваш_ключ_здесь
PORT=3000
```

**Где получить API ключ:**
1. Зайдите на https://console.anthropic.com/
2. Зарегистрируйтесь или войдите
3. Перейдите в раздел "API Keys"
4. Создайте новый ключ

### 3. Запуск сервера

```bash
npm start
```

Или для разработки с автоматической перезагрузкой:

```bash
npm run dev
```

### 4. Откройте в браузере

```
http://localhost:3000
```

## 🎯 Как использовать

1. Введите любой текст в текстовое поле
2. Или выберите один из готовых примеров
3. Нажмите "Анализировать и найти мемы"
4. Claude проанализирует текст и подберёт подходящие мемы
5. Получите результаты с описанием настроения и темы

## 🔧 API Endpoints

### POST `/api/analyze`
Анализирует текст и возвращает мемы

**Request body:**
```json
{
  "text": "ваш текст здесь"
}
```

**Response:**
```json
{
  "analysis": "Анализ текста...",
  "mood": "позитивное",
  "themes": ["работа", "пятница"],
  "memes": [
    {
      "query": "friday celebration",
      "title": "It's Friday!",
      "description": "Почему подходит...",
      "vibe": "funny"
    }
  ]
}
```

### GET `/api/health`
Проверка статуса сервера

**Response:**
```json
{
  "status": "ok",
  "hasApiKey": true,
  "timestamp": "2026-01-30T..."
}
```

## 🎨 Кастомизация

### Изменение стилей
Откройте `public/style.css` и измените CSS переменные:

```css
:root {
    --primary: #667eea;      /* Основной цвет */
    --secondary: #764ba2;    /* Вторичный цвет */
    --success: #10b981;      /* Цвет успеха */
    --error: #ef4444;        /* Цвет ошибки */
}
```

### Изменение промпта для AI
Откройте `server.js` и найдите раздел с промптом для Claude в `/api/analyze` endpoint.

### Добавление других источников изображений
В `public/script.js` измените функцию `getImageUrl()` для использования других API:
- Giphy API для GIF мемов
- Imgflip API для шаблонов мемов
- Custom мем API

## ⚠️ Важные замечания

- **API ключ** - Храните `.env` в безопасности, не коммитьте в git
- **Лимиты** - У Anthropic API есть лимиты на количество запросов
- **Изображения** - Сейчас используется Unsplash, можно интегрировать специализированные мем API
- **CORS** - Если деплоите на разные домены, настройте CORS в `server.js`

## 🚀 Деплой

### Heroku
```bash
heroku create
heroku config:set ANTHROPIC_API_KEY=ваш_ключ
git push heroku main
```

### Vercel/Netlify
Для деплоя на Vercel/Netlify нужно настроить serverless functions, так как они не поддерживают обычный Express сервер.

### VPS/Dedicated Server
```bash
pm2 start server.js --name "meme-analyzer"
pm2 save
pm2 startup
```
